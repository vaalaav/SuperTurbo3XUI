## ✨ Что это такое

**SuperTurbo3XUI** — интерактивный Bash-установщик, который подготавливает VPS на Ubuntu 24.04 LTS и разворачивает на нём связку **3x-ui, Xray и Nginx**.

Скрипт самостоятельно настраивает сетевую инфраструктуру, HTTPS, варианты веб-маскировки и инструменты защиты. После установки сервером можно управлять через отдельную консольную утилиту `my3xui`.

> Проект рассчитан на тех, кто хочет получить готовую основу сервера за один последовательный запуск, а не выполнять десятки команд вручную.

## 🚀 Быстрый старт

Подключитесь к VPS по SSH под пользователем `root`. Скачайте установщик и запустите его:

> [!CAUTION]
> **Для установки требуется чистый VPS и домен, привязанный к IP-адресу VPS.**

```bash
curl -fsSL https://raw.githubusercontent.com/vaalaav/SuperTurbo3XUI/main/install-vps.sh -o install-vps.sh
bash install-vps.sh
```

<details>
<summary><strong>Перед запуском</strong></summary>

- Чистый VPS с **Ubuntu 24.04 LTS**.
- Доменное имя с A-записью, указывающей на IP сервера.
- Доступ к серверу от имени `root`.
- Возможность принимать входящие подключения на портах SSH, 80 и 443.
- Доступ к интернету для загрузки пакетов, компонентов и SSL-сертификата.

Скрипт ориентирован на чистую систему. Не рекомендуется запускать его поверх существующей конфигурации Nginx, Xray или 3x-ui: установщик меняет системные настройки и правила сетевого экрана.

</details>

## 🛡️ Защита сервера

Установщик объединяет несколько инструментов, отвечающих за разные уровни защиты:

| Компонент | Что делает |
|:--|:--|
| **UFW** | Контролирует входящие подключения и закрывает неиспользуемые порты. |
| **Fail2Ban** | Отслеживает подозрительную активность SSH и веб-сервера, временно блокируя источники нарушений. |
| **CrowdSec** | Анализирует журналы событий и применяет решения о блокировке через firewall bouncer. |
| **nftables** | Применяет дополнительные правила фильтрации IP-адресов и подсетей. |
| **C24Be + CyberOK** | Объединяет внешние списки IP-сетей и автоматически обновляет их. |

### Автоматическая блокировка IP

По желанию во время установки можно включить дополнительный список блокировки **C24Be AS_Network_List + CyberOK Skipa**.

- Загрузка списков из открытых источников.
- Проверка и объединение IPv4-подсетей.
- Сжатие пересекающихся диапазонов.
- Белый список IP администратора и защита SSH-порта.
- Ежедневное автоматическое обновление.

Эту функцию можно включить, обновить или отключить позднее — через `my3xui`.

## 🖥️ Управление сервером

После установки доступна консольная утилита **`my3xui`**:

```bash
my3xui
```

Она открывает меню управления сервером. Основные команды:

| Команда | Назначение |
|:--|:--|
| `my3xui info` | Информация о CPU, RAM, Swap и дисках. |
| `my3xui creds` | Данные для входа в панель и список созданных инбаундов. |
| `my3xui crowdsec` | Состояние CrowdSec и активных блокировок. |
| `my3xui blocklist` | Управление дополнительными списками IP-блокировки. |
| `my3xui blocklist install` | Установить и включить блокировку. |
| `my3xui blocklist update` | Обновить списки вручную. |
| `my3xui blocklist status` | Проверить состояние блокировки. |
| `my3xui blocklist remove` | Удалить дополнительную блокировку. |
| `my3xui clean` | Запустить полную очистку установленных компонентов. |

Данные администратора дополнительно сохраняются в файле:

```text
/root/vps-credentials.txt
```

Файл доступен только root (права `600`). Храните его в безопасном месте.

## 🧭 Как проходит установка

1. **Домен и SSL** — ввод домена и контактного email, проверка DNS.
2. **Веб-маскировка** — выбор локального сайта или Reverse Proxy.
3. **Доступ к панели** — настройка или генерация логина и пароля.
4. **Защита** — включение или отключение дополнительных IP-списков.
5. **Развёртывание** — установка и настройка компонентов.
6. **Готово** — вывод основных параметров и данных для входа.

Установка интерактивная: перед началом скрипт показывает сводку выбранных параметров и запрашивает подтверждение.

## ⚠️ Важные замечания

- Поддерживаемая целевая система — **Ubuntu 24.04 LTS**.
- Установщик создаёт инбаунды, но **не создаёт пользователей 3x-ui**. Добавьте клиентов самостоятельно через веб-панель.
- Не публикуйте файл с учётными данными и не передавайте посторонним доступ к панели.
- Режим Reverse Proxy требует доступности выбранного внешнего сайта.
- Для выпуска SSL-сертификата домен должен корректно указывать на сервер, а проверка Let's Encrypt должна быть доступна извне.
- Команда `my3xui clean` выполняет масштабную очистку: удаляет 3x-ui, Xray, Nginx, CrowdSec, Fail2Ban, сертификаты, созданные правила firewall и настройки установщика. Перед запуском сохраните нужные данные и конфигурации.

## 📦 Используемые проекты

SuperTurbo3XUI использует следующие сторонние компоненты:

- [3x-ui](https://github.com/MHSanaei/3x-ui) — панель управления.
- [Xray-core](https://github.com/XTLS/Xray-core) — сетевое ядро.
- [Nginx](https://nginx.org/) — веб-сервер и маршрутизация подключений.
- [Certbot](https://certbot.eff.org/) — получение и продление SSL-сертификатов.
- [CrowdSec](https://www.crowdsec.net/) — анализ событий безопасности.
- [Fail2Ban](https://github.com/fail2ban/fail2ban) — защита от подозрительных попыток доступа.
- [C24Be / AS_Network_List](https://github.com/C24Be/AS_Network_List) — списки IP-подсетей и инструменты для их применения.
- [CyberOK / Skipa IPs](https://github.com/tread-lightly/CyberOK_Skipa_ips) — список IP-адресов сканеров SKIPA.
- [UFW](https://launchpad.net/ufw) и [nftables](https://netfilter.org/projects/nftables/) — управление сетевой фильтрацией.
