## 🚀 Быстрый старт

Подключитесь к чистому серверу **Ubuntu 24.04** или **26.04 LTS** под пользователем `root` и выполните:

~~~bash
curl -fsSL https://raw.githubusercontent.com/vaalaav/SuperTurbo3XUI/main/install-vps.sh -o /root/install-vps.sh && bash /root/install-vps.sh
~~~

> [!CAUTION]
> **Требования: чистый VPS и заранее привязанный к IP-адресу сервера домен (A-запись).**

## ✨ Что делает установщик

* **Полная автоматизация с нуля** — устанавливает актуальные пакеты, выпускает и настраивает автопродление SSL-сертификатов Let's Encrypt, оптимизирует сетевой стек (BBR) для высокой скорости.
* **2 современных XHTTP-подключения из коробки** — автоматически создаёт и настраивает **VLESS-XHTTP-PacketUP** (для мобильных сетей и жёсткой фильтрации) и **VLESS-XHTTP-StreamOne** (для максимальной скорости на домашнем интернете) с обфускацией трафика под обычный веб-серфинг, объединённые в **единую ссылку подписки**.
* **Гибкая маскировка домена** — скрывает работу прокси за реалистичным локальным веб-порталом или прозрачно проксирует выбранный вами внешний сайт.
* **Случайные реквизиты доступа** — генерирует уникальные порты, скрытые URL-пути, случайный логин и надёжный пароль для входа в панель управления.

## 🛡️ Встроенная защита

Сервер защищён от сканирования, перебора паролей и обнаружения сразу после завершения установки:

| Компонент | Назначение |
| :--- | :--- |
| **UFW Firewall** | Закрывает все лишние порты — снаружи доступны только ваш порт SSH, HTTP (80) и HTTPS (443). |
| **Anti-Probing** | Мгновенно сбрасывает прямые обращения по IP-адресу сервера на этапе TLS handshake и блокирует ботов. |
| **Fail2Ban** | Автоматически банит злоумышленников при попытках подбора пароля SSH или перебора скрытых директорий. |
| **CrowdSec** | Анализирует поведение подключений в реальном времени и блокирует известные вредоносные IP-адреса. |
| **CyberOK Skipa** | Ежедневно обновляет базу IP-адресов и подсетей сетевых сканеров и отбрасывает их пакеты на входе. |

## 🖥️ CLI-утилита `my3xui`

После установки в системе становится доступна консольная команда **`my3xui`** для быстрого контроля сервера без входа в веб-интерфейс:

~~~bash
my3xui
~~~

Также поддерживается прямой запуск нужного раздела:

* `my3xui info` — модель и частота процессора, объём оперативной памяти, тип (`NVMe` / `SSD` / `HDD`) и размер дисков.
* `my3xui creds` — актуальная ссылка на веб-панель 3x-ui, логин, пароль, ссылка единой подписки и готовые ключи `vless://` напрямую из базы данных.
* `my3xui crowdsec` — список активных блокировок CrowdSec и статистика отброшенных пакетов сканеров.
* `my3xui clean` — полное удаление всех установленных компонентов, сертификатов и правил с возвратом сервера в исходное состояние.

## 📋 Пошаговый процесс установки

1. Запустите команду установки из раздела **Быстрый старт**.
2. Укажите ваш **домен** и email для выпуска SSL-сертификата.
3. Выберите вариант маскировки (локальная заглушка или свой URL) и подтвердите случайные логин и пароль панели.
4. Дождитесь завершения настройки (~2–3 минуты) — в конце в терминале появятся ссылка на панель, данные для входа и готовая ссылка подписки для импорта в клиент.
