## 🚀 Быстрый старт

Подключитесь к чистому серверу **Ubuntu 24.04** или **26.04 LTS** под пользователем `root` и выполните:

~~~bash
curl -fsSL https://raw.githubusercontent.com/vaalaav/SuperTurbo3XUI/main/install-vps.sh -o /root/install-vps.sh && bash /root/install-vps.sh
~~~

> [!ВНИМАНИЕ]
> **Требования: чистый VPS с 1+ CPU, 1+ GB RAM и заранее привязанным к IP-адресу сервера доменом (A-запись).**

## ✨ Основной функционал

* **Два устойчивых XHTTP-подключения из коробки** — создаются **VLESS-XHTTP-PacketUP** (для мобильных сетей и жёсткой фильтрации) и **VLESS-XHTTP-StreamOne** (для максимальной скорости на домашнем интернете) с обфускацией под обычный веб-трафик и **единой ссылкой подписки**.
* **Автоматическое именование локаций** — скрипт сам определяет страну сервера по его внешнему IP и присваивает подключениям понятные имена с флагом и нумерацией (например, `🇳🇱 Нидерланды 1`, `🇳🇱 Нидерланды 2`).
* **Гибкая маскировка домена** — скрывает работу прокси за реалистичным локальным веб-порталом (`myfakesite`) или прозрачно проксирует выбранный вами внешний сайт.
* **Криптостойкие реквизиты доступа** — автоматически генерирует случайные локальные порты, скрытые URL-пути, сложный 12-символьный логин и 20-символьный пароль со спецсимволами.
* **Полная автонастройка окружения** — устанавливает официальный Nginx, выпускает и настраивает автопродление SSL-сертификатов Let's Encrypt, применяет сетевые оптимизации ядра Linux (BBR).

## 🛡️ Встроенная защита

| Компонент | Назначение |
| :--- | :--- |
| **UFW Firewall** | Закрывает все лишние порты — снаружи доступны только SSH, HTTP (80) и HTTPS (443). |
| **Anti-Probing** | Мгновенно сбрасывает прямые обращения по IP-адресу сервера на этапе TLS handshake и отсекает ботов. |
| **Fail2Ban** | Автоматически блокирует попытки перебора паролей SSH и сканирования скрытых директорий. |
| **CrowdSec** | Анализирует поведение подключений в реальном времени и блокирует известные вредоносные IP-адреса. |
| **C24Be + CyberOK Skipa** | Объединяет и сжимает базы IP-подсетей ведомственных структур РФ и сетевых сканеров в `nftables` с ежедневным автообновлением. |

## 🖥️ CLI-утилита `my3xui`

После установки в системе доступна консольная утилита **`my3xui`** для управления сервером из терминала:

~~~bash
my3xui
~~~

Поддерживаемые разделы и прямые команды:

* `my3xui info` — информация о процессоре, оперативной памяти, типе и объёме дисков.
* `my3xui creds` — ссылка на панель 3x-ui, логин, пароль, ссылка единой подписки и готовые ключи `vless://` из базы данных.
* `my3xui crowdsec` — состояние CrowdSec, активные блокировки и статистика отброшенных пакетов.
* `my3xui blocklist [install|update|remove|status]` — установка, ручное обновление, проверка статуса или удаление объединённого чёрного списка `C24Be + CyberOK Skipa`.
* `my3xui clean` — полное удаление всех установленных компонентов, сертификатов, правил фаервола и возврат сервера в исходное состояние.

## 📋 Порядок установки

1. Запустите команду из раздела **Быстрый старт**.
2. Введите ваш **домен** и email для выпуска SSL-сертификата.
3. Выберите режим маскировки, подтвердите сгенерированные логин и пароль панели и включение блокировки сканеров.
4. Дождитесь завершения настройки (~2–3 минуты) — в конце в терминале отобразятся все данные для входа и готовая ссылка подписки.
